# Proxy Image Gen (NovelAI / OpenAI-Compatible) — v2.0

Extension สำหรับ SillyTavern ที่แยกงานเจนรูปเป็น 2 Connection

```
Connection 1  →  [ตรวจ/แก้ prompt]  →  Connection 2  →  รูปเข้าแชท (ปัดขวาเพื่อแก้ prompt แล้วเจนใบใหม่)
Connection Profile ของ ST                NovelAI Official
หรือ Custom OpenAI-compatible            หรือ Reverse Proxy
```

## ติดตั้ง
วางโฟลเดอร์นี้ใน `SillyTavern/public/scripts/extensions/third-party/` แล้วรีเฟรช
ไฟล์ที่ต้องมี: `manifest.json`, `index.js`, `settings.html`, `style.css`

## โมเดลที่ค้นเว็บได้
ติ๊ก **"โมเดลนี้ค้นเว็บได้"** ในหมวด ① เมื่อใช้โมเดลตระกูล `*-search` หรือมี grounding — จะเปลี่ยนกฎ identity จาก "ดึงจากความจำแล้วประเมินความมั่นใจ" เป็น "ค้นแท็กจาก booru ก่อน แล้วค่อยใช้บันไดถอยเป็นทางสุดท้าย" พร้อมสั่งห้ามใส่ citation กลับมา
ระบบยังกรอง citation ที่หลุดมาให้อีกชั้น: `[1]` `[^2]` `【…】` markdown link, URL เปล่า และบล็อก Sources ท้ายคำตอบ โดยไม่แตะไวยากรณ์ `1.2::…::`

## โหมดคิดก่อนตอบ (CoT)
หมวด ① เลือกได้ 3 ระดับ
- **ปิด** — คายแท็กออกมาเลย เร็วสุด เหมาะกับภาพเดี่ยว
- **เบา** — ให้โมเดลคิดใน `<planning>` (cast / ตำแหน่ง / ส่วนสูง / interaction / ฉาก) ก่อนคายแท็กในคำตอบเดียว บล็อกนี้ถูกตัดทิ้งก่อนส่งต่อ ระบบเผื่อโควตาคำตอบให้ 1.8 เท่าอัตโนมัติ
- **หนัก** — ยิง Connection 1 สองรอบ รอบแรกวิเคราะห์ฉากเป็นข้อความ รอบสองแปลงเป็นแท็ก แม่นสุดกับฉาก 3-4 ตัวละคร แต่ช้าและเปลืองกว่าเท่าตัว

ผลวิเคราะห์ทั้งสองโหมดพิมพ์ลง console ตรวจย้อนได้ว่าโมเดลเข้าใจฉากถูกไหม

## Prompt Templates
หมวด ② แก้ได้เฉพาะ **System** ของแต่ละโหมด (พร้อมปุ่มรีเซ็ตทีละโหมด/ทั้งหมด)
ส่วน user message ระบบประกอบให้เองตามโหมด จึงไม่ต้องดูแล

ทุก default template สอนโมเดลเรื่อง:
- **Cast ทั้งฉาก** (โหมด last/free) ไล่ชื่อตัวละครทุกตัวที่ปรากฏในข้อความ ไม่ใช่แค่ `{{char}}` + count tag ต้องตรงกับ cast
- **ตำแหน่ง** ยึดตำแหน่งสุดท้ายในข้อความ เรียงบล็อกซ้าย→ขวา และเสริมด้วย relation/foreground/background
- **ส่วนสูงและระดับสายตา** แท็ก build สัมบูรณ์ + `height difference` ทั้งสองฝั่ง + เงย/ก้มตามระดับสายตาจริง (นั่ง/คุกเข่าชนะส่วนสูงดิบ)
- **Style tail** ปิดท้ายทุก prompt ทั้ง 5 โหมด ด้วยแท็กสไตล์ของแฟรนไชส์ (genshin impact / arknights / project sekai ฯลฯ) + rendering style + `masterpiece, very aesthetic, absurdres, best quality`
- **การหาแท็กตัวละคร** ระบุผลงานต้นทางก่อน แล้วดึงแท็กจากคลังที่ใช้ scheme เดียวกัน (Danbooru เป็นหลัก, Gelbooru / Safebooru / AIBooru / e621 สำหรับ furry) พร้อมบันไดถอย 3 ชั้น: มั่นใจ → ใส่แท็กตัวละคร+ซีรีส์ / รู้แค่ซีรีส์ → ใส่แท็กซีรีส์อย่างเดียว / ไม่รู้จัก → บรรยายลักษณะล้วน ห้ามเดาเด็ดขาด
- **Pinned tag glossary** (หมวด ③) ปักหมุดแท็กที่โมเดลมักจำผิดไว้เอง ระบบแนบเข้า Connection 1 ทุกครั้งและสั่งให้ใช้สะกดตามนั้นตรง ๆ
- ลำดับแท็กตามที่ NAI แนะนำ + ห้ามใส่แท็กเฟรมชนกัน + แท็กที่ถูกเปลี่ยนชื่อ (`peace sign` ไม่ใช่ `v`)
- **Density**: `1.2::tag, tag ::` ปิดด้วย `::` เปล่า, `-1::hat ::` เพื่อลบของ, ใช้ 2-3 จุดพอ และห้ามใช้ `(tag:1.2)` แบบ SD หรือ `|`

โหมด **User** ใช้ `{{persona}}` เป็นลักษณะถาวร (เพศ รูปร่าง ทรงผม สีตา) และใช้ข้อความล่าสุดเป็นสถานะปัจจุบัน (ชุดที่ใส่อยู่ ผมเปลี่ยนทรง สีหน้า สถานที่) เมื่อขัดกันในเรื่องชั่วคราว ให้ยึดตามฉาก

### {{extra}}
ช่อง **Extra instruction** ในหมวด ② คือค่าของ `{{extra}}` — แทรกท้าย user message เป็นบล็อก `--- Extra instruction ---` ทุกโหมด และข้อความหลัง `/pxi` จะถูกต่อเข้ากับช่องนี้

## Cheatsheet (หมวด ⑥)
มี dropdown ให้เลือกอ่านแยกตาม engine — เลือกแล้วปุ่มหัวข้อจะเปลี่ยนตาม และปุ่มบันทึก .md จะได้เฉพาะฝั่งที่เลือก

**NovelAI Diffusion (10 หัวข้อ)** Artist tags • source#/target#/mutual# • Density/น้ำหนักแท็ก • Quality/Aesthetic/Special tags • Undesired Content ทางการ • Medium/Art style/Coloring/FX • มุมกล้อง/เฟรม/แสง • Character & Costume variant tags • NSFW / rating tags (18+) • ค่าที่แนะนำ + เกร็ด Anlas

**GPT-Image (7 หัวข้อ)** เลือกโมเดล + ขนาดภาพ • หลักการเขียน prompt • องค์ประกอบภาพและคน • ข้อจำกัดและการแก้ภาพ • ตัวหนังสือในภาพ • พารามิเตอร์และค่าใช้จ่าย • ใช้กับส่วนขยายนี้

## Connection 1 (โหมด Custom)
มีชุดเดียวกับ Connection 2: **โหมด URL** 3 แบบ (อัตโนมัติ / กำหนด path เอง / ใช้ URL ตรง ๆ) พร้อมบรรทัดพรีวิวปลายทางจริง, ปุ่ม **เชื่อมต่อ** ที่ดึง `/models` มาเติม dropdown, ปุ่ม **ทดสอบ** ที่ยิงข้อความสั้นไปตรวจว่าตอบกลับได้จริง และแถบสถานะบอกผล
โหมดอัตโนมัติต่อ `chat/completions` ให้ ส่วนโหมด path เองใช้กับ proxy ที่ใช้ path แปลก เช่น `v2/messages`

## GPT-Image
เลือกปลายทางเป็น **GPT-Image** ในหมวด ④ ใช้ Base URL / API Key / Timeout / โหมด URL **ชุดเดียวกับ Custom** ต่างกันแค่รูปแบบ payload และหน้าตาของหมวด ⑤

พารามิเตอร์ที่รองรับ: `model` (gpt-image-1 / 1-mini / 1.5 / 2 / chatgpt-image-latest), `size` (auto หรือกรอกเอง ไม่ล็อกสเปก), `quality`, `output_format`, `output_compression` (เฉพาะ jpeg/webp), `background`, `moderation` และช่องข้อความต่อท้าย prompt
ระบบไม่ส่ง `response_format` เพราะ GPT-Image คืน base64 เสมอ และไม่มี negative prompt / seed / steps / CFG ให้ตั้ง
สำหรับ `gpt-image-2` ระบบปัดด้านให้หารด้วย 16 ลงตัวอัตโนมัติ พร้อมเตือนเมื่ออัตราส่วนเกิน 1:3–3:1 หรือขนาดเกินเพดาน

**Template แยกครบทั้ง 6 โหมด** เป็น prompt แบบประโยคบรรยาย (ไม่ใช่แท็ก) พร้อม dropdown **ประเภทภาพ**: Anime / Semi-realistic / Realistic / Painterly illustration
ตัวแก้ template ในหมวด ② จะสลับชุดตามปลายทางที่เลือกใน Connection 2 ให้เอง และมีแถบบอกว่ากำลังแก้ชุดไหนอยู่

## Connection 2
**โหมด URL** (โหมด Custom) เลือกได้ 3 แบบ พร้อมบรรทัดพรีวิวปลายทางจริงใต้ช่อง Base URL
- **อัตโนมัติ** — เติม `/v1` ให้เมื่อยังไม่มี แล้วต่อ `images/generations` / `models`
- **กำหนด path เอง** — ต่อ path ที่กรอกเองแบบตรงตัว ไม่เติมอะไรเลย (เช่น base `https://host/sdapi` + path `txt2img`) เว้น path โมเดลว่างไว้ = ไม่ดึงรายชื่อโมเดล
- **ใช้ URL นี้ตรง ๆ** — ยิงไปที่ URL นั้นทั้งดุ้น รองรับ query string และ endpoint ทรงไหนก็ได้

กดปุ่ม **เชื่อมต่อ** เพื่อตรวจการเชื่อมต่อและโหลดรายชื่อโมเดล — โหมด NovelAI จะแสดง tier, ยอด Anlas และสิทธิ์เจนรูปฟรี ส่วนโหมด Custom จะดึง `/models` มาเติมใน dropdown ให้เลือก (พิมพ์ชื่อโมเดลเองก็ได้ถ้า endpoint ไม่มี `/models`)
ปุ่ม **ทดสอบเจนรูป** ยิงจริง 1 ใบแล้วส่งรูปเข้าแชทเหมือนการเจนปกติ (ปัดขวาเพื่อแก้ prompt แล้วเจนใหม่ได้ ลบทิ้งได้ตามปกติ)
ปุ่ม **ค้นหา endpoint** (โหมด Custom) ไล่ยิง path ที่พบบ่อย 11 แบบด้วย body ว่าง แล้วรายงานว่า path ไหนมีอยู่จริง — ใช้เมื่อ `/models` ตอบ 200 ได้แต่ตัวเจนรูปตอบ 404

**หมายเหตุเรื่อง mixed content:** ส่วนขยายนี้ยิงจากเบราว์เซอร์โดยตรง (ต่างจากโหมด NovelAI ที่วิ่งผ่านเซิร์ฟเวอร์ ST) ถ้าเปิด SillyTavern ผ่าน `https://` แล้ว Base URL เป็น `http://` เบราว์เซอร์จะบล็อกทิ้งก่อนถึงเซิร์ฟเวอร์เสมอ — ส่วนขยายจะตรวจจับและแจ้งให้ก่อนยิง

### รองรับโมเดลใหม่โดยไม่ต้องอัปเดต extension
ช่อง Model เป็นช่องพิมพ์ + รายการแนะนำ พอ NovelAI ปล่อยรุ่นใหม่ (เช่น V5) พิมพ์ชื่อโมเดลได้ทันที
ถ้าอยากให้ทีมทั้งหมดได้รายชื่อเดียวกัน ใส่ **Remote model list** ชี้ไปที่ไฟล์ JSON บน GitHub ของตัวเอง:
```json
["nai-diffusion-5-full",
 {"id":"nai-diffusion-5-curated","label":"V5 Curated","suffix":"...","negative":"..."}]
```
ใส่ `suffix` กับ `negative` มาด้วยได้ ปุ่ม "ใส่ค่าที่ NovelAI แนะนำ" จะหยิบไปใช้กับโมเดลนั้นให้เอง • ติ๊กให้ดึงอัตโนมัติตอนเปิด ST ได้

## NovelAI Official
กรอกคีย์แล้วกดบันทึก — คีย์ถูกเก็บในช่อง NovelAI ของ SillyTavern เอง (`api_key_novel`) ไม่ได้เก็บในไฟล์ตั้งค่าของ extension
คำขอวิ่งผ่าน `/api/novelai/generate-image` ของเซิร์ฟเวอร์ ST จึงไม่ติด CORS
โมเดล: V4.5 Full / V4.5 Curated / V4 Full / V4 Curated / V3 / Furry V3

**Avoid spending Anlas (Opus tier)** — เปิดไว้ระบบจะย่อภาพให้ไม่เกิน 1024x1024 (คงอัตราส่วน ปัดเป็นทวีคูณของ 64) และตัด steps เหลือ 28 เฉพาะตอนยิงจริง ไม่แก้ค่าที่ตั้งไว้ในหน้าตั้งค่า
**View my Anlas** — เช็คยอด Anlas, tier และสิทธิ์เจนรูปฟรีจาก `/api/novelai/status`

**ข้อจำกัดที่ต้องรู้:** เซิร์ฟเวอร์ ST ส่ง `char_captions: []` เสมอ แปลว่าไวยากรณ์ `|` (base prompt | character prompt) ของ V4 **ใช้ไม่ได้** ผ่านเส้นทางนี้ default template จึงเขียนเป็น prompt ก้อนเดียว ถ้า proxy ส่วนตัวรองรับ char_captions ค่อยแก้ template เพิ่ม `|` เอง

### สไตล์ภาพ (หมวด ⑤)
ทุกอย่างที่เกี่ยวกับสไตล์อยู่ในกล่อง GPT-Image กล่องเดียว: **สไตล์เริ่มต้น** (14 แบบ + กำหนดเอง), ช่องเขียนสไตล์เอง, ติ๊กจำสไตล์ และติ๊กจำแยกตามโหมด
สไตล์เริ่มต้นทำสองหน้าที่ — เป็นค่าตั้งต้นที่ popup เลือกให้ตอนกดสร้าง และเป็นค่าที่ใช้ตรง ๆ เมื่อติ๊ก "จำสไตล์ภาพไว้" (รวมถึงตอนใช้ `/pxi` และตอนปัดเจนใบใหม่ ซึ่งไม่ผ่าน popup)

### สไตล์หน้าการ์ตูน (ฝั่ง NovelAI)
กดสร้างโหมด **Manga Panel** จะเด้ง popup ถามว่าอยากได้หน้าแบบไหน 6 แบบ: ขาวดำ+สกรีนโทน (คลาสสิก) / ขาวดำเส้นสะอาด / สีเต็ม / เว็บตูน / ซีเปีย / ร่างดินสอ
ติ๊ก "จำไว้" เพื่อไม่ให้ถามอีก ปลดติ๊กได้ที่หมวด ⑤ • ค่าที่เลือกถูกส่งไปพร้อม template ชุด Manga Panel ให้ Connection 1 เขียน prompt

### เลือกสไตล์ตอนกดสร้าง
เมื่อ **ชุดพารามิเตอร์ = GPT-Image** การกดสร้างภาพจากเมนู Wand หรือปุ่มในหน้าตั้งค่าจะเด้ง popup ให้เลือกสไตล์ก่อน (14 แบบ + สไตล์ที่เขียนเอง) พร้อมติ๊ก **"จำสไตล์นี้ไว้"** ถ้าไม่อยากให้ถามอีก — ปลดติ๊กได้ที่หมวด ⑤
สไตล์ที่เลือกจะถูกส่งไปพร้อม template และข้อมูลฉากทั้งหมดให้ Connection 1 เขียน prompt ในรอบเดียว
**ทั้ง popup และการใส่สไตล์ยึดจากหมวด ⑤ Image Parameters อย่างเดียว** ไม่เกี่ยวกับว่าชุด template ในหมวด ③ ตั้งเป็นอะไรอยู่
- **จำสไตล์แยกตามโหมด** (หมวด ⑤) ให้ Portrait, Manga ฯลฯ จำคนละสไตล์ได้
- **สไตล์ที่เขียนเอง** เลือก "กำหนดเอง" ในหมวด ② แล้วพิมพ์คำสั่งสไตล์ของตัวเอง

### เจนไม่ผ่านแล้วแก้ต่อได้ทันที
ถ้า Connection 2 ตีกลับ (โดนกรองเนื้อหา คิวเต็ม พารามิเตอร์ผิด) จะขึ้น popup บอกสาเหตุ พอกด **"แก้ prompt แล้วลองใหม่"** จะเด้งช่องแก้ prompt กลับมาให้ทันที แก้แล้วยิงต่อได้เลยโดยไม่ต้องเริ่มใหม่ทั้งกระบวนการ
ลองได้สูงสุด 5 ครั้งต่อรอบ แล้วหยุดเอง กันวนไม่จบและกันเปลืองเครดิต • ใช้ได้ทั้งตอนกดสร้าง ตอนปัดเจนใบใหม่ และปุ่มทดสอบเจนรูป

## Vibe — ชุดแท็กที่ใช้ซ้ำ (หมวด ⑤)
บันทึกชุดแท็กสไตล์ที่ใช้บ่อยไว้เป็นพรีเซ็ต แล้วเรียกใช้ซ้ำได้ทุกโหมด เพื่อให้ภาพชุดเดียวกันหน้าตาไปทางเดียวกัน
- สร้าง / แก้ / ลบ ได้ในกล่อง Vibe มีชื่อ, แท็ก และบันทึกช่วยจำ
- **ฝั่ง NovelAI** แท็กถูกต่อเข้า prompt ก่อน suffix • **ฝั่ง GPT-Image** ใส่เป็นคำสั่งใน system แทน (เพราะ prompt เป็นประโยค)
- เลือกได้ตอนกดสร้างจาก popup หรือติ๊ก "จำ vibe ไว้" เพื่อใช้ค่าเดิมตลอด

**หมายเหตุ:** นี่ไม่ใช่ Vibe Transfer ของ NovelAI (ที่เข้ารหัสภาพเป็น embedding และเสีย Anlas) เพราะเซิร์ฟเวอร์ SillyTavern ตัด `reference_image_multiple` ทิ้งเสมอ — อันนี้เป็นพรีเซ็ตแท็กที่ให้ผลใกล้เคียงโดยไม่เสีย Anlas และใช้ได้ทั้งสอง engine

## Image Parameters
จัดเป็น 4 กลุ่ม: **ขนาดภาพ** (dropdown สำเร็จรูป + ช่องกำหนดเอง + ปุ่มบันทึก, ปัดเป็นทวีคูณของ 64 อัตโนมัติ, มีบรรทัดบอก "จะส่งจริง WxH" หลังผ่าน Anlas guard) • **การสุ่มภาพ** (Sampler, Scheduler, Steps, CFG, Seed, Upscale, Timeout) • **ตัวเลือกเสริม** (Variety boost, Decrisper, SMEA; SMEA DYN ปิดถาวรเพราะทำให้ภาพเพี้ยนบน V4 ขึ้นไป) • **แท็กประกอบ** (prefix / suffix / negative / extra body)

ค่าเริ่มต้นของขนาดคือ **768x1344 (3:4)** และมี 1344x768 (4:3) ให้เลือกคู่กัน
ปุ่ม **ใส่ค่าที่ NovelAI แนะนำ** ตั้งทุกค่าในหมวดนี้ให้ตามโมเดลที่เลือก **ยกเว้นขนาดภาพ** ที่คงไว้ตามที่ตั้งเอง

## การปัดรูปเพื่อเจนใหม่
ปัดขวาที่รูปใบสุดท้าย → popup ให้ตรวจ/แก้ prompt → เจนเพิ่มเข้า media array (ปัดซ้ายย้อนดูใบเก่า)

**สำคัญ:** SillyTavern มี Image Generation ในตัวที่ดักปัดรูปเหมือนกัน ถ้า User Settings → *Image Swipe Behavior* ตั้งเป็น **Generate** มันจะเจนรูปซ้อนอีกใบด้วยค่าของ Stable Diffusion panel เอง (ขนาด, negative prompt, upscale คนละชุดกับที่ตั้งไว้ที่นี่)
ติ๊ก **"ให้ extension นี้จัดการการปัดรูปคนเดียว"** (เปิดไว้เป็นค่าเริ่มต้น) ระบบจะสลับค่านั้นเป็น Rollover ให้อัตโนมัติ

## เพอร์โซนาในโหมด Last Message
เดิม persona ของ `{{user}}` ถูกส่งไปทุกครั้ง ทำให้ฉากที่ผู้ใช้ไม่ได้อยู่ในเฟรมโดนโมเดลลากตัวละครที่สองเข้ามาเอง ตอนนี้มี 3 โหมดในหมวด ③
- **อัตโนมัติ** (ค่าเริ่มต้น) — ส่ง persona ก็ต่อเมื่อข้อความล่าสุดมีชื่อผู้ใช้ เป็นข้อความของผู้ใช้เอง หรือมีสรรพนามบุรุษที่ 2 (คุณ / นาย / แก / you) ถ้าไม่พบจะไม่ส่ง และสั่งโมเดลตรง ๆ ว่าอย่าวาดและอย่านับตัวละครนี้
- **บังคับใส่เสมอ** / **บังคับตัดออกเสมอ** สำหรับเคสที่ตรวจพลาด

การตรวจใช้โค้ดล้วน ๆ (เทียบชื่อ + regex สรรพนาม) **ไม่เรียก AI และไม่กิน token**
บรรทัดใต้ dropdown บอกผลการตรวจของฉากปัจจุบันพร้อมตัวอย่างข้อความที่ใช้ตัดสิน อัปเดตเองเมื่อมีข้อความใหม่ / แก้ / ลบ / ปัด / สลับแชท และมีปุ่มรีเฟรชกดเองได้
ส่วนการตรวจจริงตอนกดเจนอ่านฉากสด ๆ เสมอ ไม่มีทางค้างไม่ว่าจะเปิดหน้าตั้งค่าค้างไว้นานแค่ไหน

## พับจอ / สลับแอป และปุ่ม Stop
- **ยิงผ่านเซิร์ฟเวอร์ ST (Connection 1)** — ติ๊ก "ยิงผ่านเซิร์ฟเวอร์ SillyTavern" ในหมวด ① เปิดไว้เป็นค่าเริ่มต้น จะให้ Node ที่รันใน Termux เป็นคนยิงไปหา proxy แทนเบราว์เซอร์ คำขอจึงไม่ตายตอนพับจอ เพราะ Termux ถือ wakelock ของตัวเองอยู่แล้ว
  ใช้ได้เฉพาะเมื่อ URL ลงท้ายด้วย `/chat/completions` (โหมดอัตโนมัติและโหมด path ปกติ) ส่วนโหมด "ใช้ URL นี้ตรง ๆ" จะยิงตรงจากเบราว์เซอร์เหมือนเดิม บรรทัดพรีวิวใต้ Base URL บอกว่ากำลังใช้ทางไหนอยู่
  คีย์ถูกส่งใน body ของคำขอ ไม่ได้เขียนลง secret store ของ ST จึงไม่ไปสลับ Custom API key ที่ตั้งไว้เดิม
- **Connection 2 (NovelAI Official)** วิ่งผ่านเซิร์ฟเวอร์ ST อยู่แล้วตั้งแต่ต้น จึงไม่มีปัญหานี้ ส่วนโหมด Custom/GPT-Image ยังยิงตรงจากเบราว์เซอร์
- **พับจอแล้วยังยิงต่อได้** — timeout นับเฉพาะเวลาที่หน้าเว็บเปิดอยู่จริง เดิมใช้ `setTimeout` ตรง ๆ ซึ่งเบราว์เซอร์มือถือจะหน่วงไว้ตอนพับจอแล้วยิงรัวตอนกลับมา ทำให้คำขอที่ยังวิ่งอยู่ถูกตัดทิ้งทันทีที่กลับมาดู
- ขอ **Wake Lock** ระหว่างเจน (ถ้าเบราว์เซอร์รองรับ) เพื่อลดโอกาสที่จอดับแล้วระบบพักหน้าเว็บ
- **ปุ่ม Stop** สีแดงข้างปุ่มส่งของ SillyTavern โผล่เฉพาะตอนกำลังทำงาน กดแล้วยกเลิกคำขอที่วิ่งอยู่ทันที ทั้ง Connection 1 และ 2
- **แถบสถานะ** เส้นบางเหนือช่องพิมพ์ **แยกหลอดตาม connection** — ① เลือกสไตล์ → วิเคราะห์ฉาก → เขียน prompt → รอตรวจ prompt (เขียว) แล้วรีเซ็ตเป็น ② เจนรูป → บันทึกรูป → เสร็จสิ้น (เหลือง) จะได้รู้ว่าค้างอยู่ที่ connection ไหน

**ข้อจำกัดที่แก้ไม่ได้:** ถ้าระบบปฏิบัติการฆ่าแท็บทิ้งจริง ๆ (พับจอนานมาก หรือ RAM ไม่พอ) คำขอจะหลุดไปด้วย ไม่มีทางกู้ในฝั่งเบราว์เซอร์

## Context Budget
จำกัดข้อความล่าสุด / ตัวอักษรต่อข้อความ / เพดานรวม, ตัด HTML + UI module block + code block ออกก่อนส่ง
ค่ามาตรฐาน: ข้อความล่าสุด **0** • ตัด/ข้อความ **1200** • เพดานรวม **10000**

**ทำไมถึงเป็น 0** — จะอ่านเฉพาะข้อความล่าสุดข้อความเดียว ไม่ย้อนไปไกล ทำให้ภาพตรงกับฉากปัจจุบันที่สุด และลดโอกาสที่เนื้อหาเก่าที่สุ่มเสี่ยงจะไปกระตุ้นฟิลเตอร์ของ Connection 1
ตั้งมากกว่า 0 เมื่อจำเป็นเท่านั้น เช่นโหมด **Manga Panel** ที่ต้องใช้หลายฉากมาแบ่งช่อง (แนะนำ 2-4)
ช่อง "ตัด/ข้อความ" คูณ 3 = ความยาวสูงสุดของข้อความล่าสุด และหน้าตั้งค่ามีบรรทัดคำนวณสด ๆ พร้อมเตือนเมื่อค่าต่ำ/สูงเกินไปหรือ Max tokens ของ Connection 1 น้อยจน prompt ถูกตัดกลางคัน
ปุ่ม **Preview** ดู payload จริงของ Connection 1 พร้อมนับ token
