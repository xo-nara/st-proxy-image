① Connection 1 — Prompt Maker
รองรับโปรไฟล์แบบ Chat Completion และ Text Completion • เว้นไว้ = ใช้โปรไฟล์ที่กำลังเปิดอยู่
อย่าลืมกดปุ่ม Save (💾) ใน Connection Manager หลังสร้างหรือแก้โปรไฟล์ — โปรไฟล์ที่ยังไม่เซฟจะไม่ถูก detect และค่าจะรีเซ็ตทุกครั้งที่สลับโปรไฟล์
ยังไม่พบโปรไฟล์ที่บันทึกไว้เลย — ไปที่ Connection Manager สร้างโปรไฟล์แล้วกด Save ก่อน แล้วค่อยกดปุ่มรีเฟรช

ยังไม่ได้เชื่อมต่อ — กรอกค่าด้านล่างแล้วกด "เชื่อมต่อ"
เปิดไว้ = ให้ Node ที่รันอยู่ใน Termux เป็นคนยิงไปหา proxy แทนเบราว์เซอร์ คำขอจึงไม่ตายตอนพับจอ (Termux ถือ wakelock ของตัวเองอยู่แล้ว)
ใช้ได้เฉพาะเมื่อ URL ปลายทางลงท้ายด้วย /chat/completions เท่านั้น — โหมด "ใช้ URL นี้ตรง ๆ" หรือ path แปลก ๆ จะยิงตรงจากเบราว์เซอร์เหมือนเดิม
ปิดไว้ = ยิงตรงจากเบราว์เซอร์ เร็วกว่าเล็กน้อยแต่จะหลุดถ้าพับจอ
รายการจะขึ้นหลังกด "เชื่อมต่อ" — ถ้า endpoint ไม่มี /models ให้พิมพ์ชื่อโมเดลเองด้านล่าง
โหมด CoT ทั้งสองแบบมีขั้นตอน "หาแท็กตัวละคร" อยู่ในตัว — บังคับให้โมเดลระบุชื่อผลงานต้นทาง แล้วประเมินความมั่นใจก่อนจะใส่แท็ก ถ้ารู้จักแค่ซีรีส์ก็ใส่แท็กซีรีส์อย่างเดียวแทนการเดา
เพดานความยาวคำตอบไม่ใช่ปริมาณที่จะถูกใช้จริง ตอบสั้นก็จ่ายสั้น แต่ถ้าตั้งต่ำเกินแท็กจะถูกตัดกลางคัน — ฉาก 3-4 ตัวละครควรอยู่ที่ 600 ขึ้นไป
โหมด CoT เบาจะเผื่อโควตาให้อัตโนมัติ 1.8 เท่า • โหมดหนักยิง Connection 1 สองรอบ (ช้าและเปลืองกว่า แต่แม่นที่สุดกับฉากหลายตัวละคร) • ผลวิเคราะห์ดูได้ใน console
② Context Budget
ค่าที่แนะนำ
ข้อความล่าสุด 0 • ตัด/ข้อความ 1200 • เพดานรวม 10000
แนะนำให้ใช้ 0 — อ่านเฉพาะข้อความล่าสุดข้อความเดียว ไม่ย้อนไปไกล ตรงกับฉากปัจจุบันที่สุด และลดโอกาสที่เนื้อหาเก่าที่สุ่มเสี่ยงจะไปกระตุ้นฟิลเตอร์ของ Connection 1
ช่อง "ตัด/ข้อความ" คูณ 3 คือความยาวสูงสุดของข้อความล่าสุด เช่น 1200 = ข้อความล่าสุดได้ 3600 ตัวอักษร
ตั้งมากกว่า 0 เมื่อจำเป็นจริง ๆ เท่านั้น เช่นโหมด Manga Panel ที่ต้องใช้หลายฉากมาแบ่งช่อง
ถ้า Connection 1 ไม่ยอมตอบหรือช้ามาก ให้ลดเพดานรวมลงก่อนเป็นอย่างแรก
③ Image Prompt Templates
สองชุดเก็บแยกกันคนละที่ สลับไปมาได้ตลอด ที่แก้ไว้ไม่หายและไม่ทับกัน
ข้อความนี้คือค่าของ {{extra}}
ถูกแทรกท้าย user message ที่ระบบประกอบให้ เป็นบล็อก --- Extra instruction --- ก่อนบรรทัดปิดท้าย ใช้ได้ทุกหมวด
ข้อความที่พิมพ์หลัง /pxi จะถูกต่อเข้ากับช่องนี้ (ช่องนี้ขึ้นก่อน)
ช่อง System ด้านบนไม่ต้องเขียน {{extra}} เอง
อัปเกรดจากเวอร์ชันก่อน? template ที่บันทึกไว้จะไม่ถูกเขียนทับอัตโนมัติ — กด "รีเซ็ตทั้งหมด" เพื่อรับ default ตัวใหม่ (cast/ตำแหน่ง/ส่วนสูง/style tail)
โหมด Manga Panel: โหมดนี้ใช้หลายฉากมาแบ่งช่อง ถ้า "ข้อความล่าสุด" ในหมวด ② เป็น 0 จะได้แค่ฉากเดียว — ตั้งเป็น 2-4 ก่อนใช้โหมดนี้ • แนะนำขนาดแนวตั้ง (เช่น 768x1344) สำหรับ 4koma แนวตั้ง และแนวนอนสำหรับสตริปแนวนอน • ถ้าอยากได้หน้าขาวดำจริง ๆ ให้เคลียร์ช่อง Positive suffix ที่มี very aesthetic/masterpiece ออกก่อน เพราะมันดันภาพไปทางภาพสีเดี่ยว
