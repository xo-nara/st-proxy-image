① Connection 1 — Prompt Maker
รองรับโปรไฟล์แบบ Chat Completion และ Text Completion • เว้นไว้ = ใช้โปรไฟล์ที่กำลังเปิดอยู่
อย่าลืมกดปุ่ม Save (💾) ใน Connection Manager หลังสร้างหรือแก้โปรไฟล์ — โปรไฟล์ที่ยังไม่เซฟจะไม่ถูก detect และค่าจะรีเซ็ตทุกครั้งที่สลับโปรไฟล์
ยังไม่พบโปรไฟล์ที่บันทึกไว้เลย — ไปที่ Connection Manager สร้างโปรไฟล์แล้วกด Save ก่อน แล้วค่อยกดปุ่มรีเฟรช

③ Context Budget
ค่าที่แนะนำ
ข้อความล่าสุด 3-8 (ค่าแนะนำ 4) • ตัด/ข้อความ 300-1200 (ค่าแนะนำ 600) • เพดานรวม 1000-10000 (ค่าแนะนำ 4000)
ช่อง "ตัด/ข้อความ" คูณ 3 คือความยาวสูงสุดของข้อความล่าสุด เช่น 600 = ข้อความล่าสุดได้ 1800 ตัวอักษร
ฉากที่มีตัวละครหลายตัวให้เพิ่ม "ตัด/ข้อความ" เป็น 800-1000 และ Max tokens ของ Connection 1 เป็น 500-600 ไม่งั้น prompt จะถูกตัดกลางคัน
ถ้าตั้งสูงเกินจน Connection 1 ไม่ยอมตอบหรือช้ามาก ให้ลดเพดานรวมลงก่อนเป็นอย่างแรก
